## How to Add Yourself

When you contribute to finspect, please add yourself to this file:

```
- **Your Name** - *Brief description of contribution* - [GitHub username](https://github.com/username)
```

Categories of contribution:

- Code contributions
- Documentation improvements
- Bug reports and fixes
- Feature suggestions
- Testing and QA
- Community support

All contributions are appreciated, no matter how small.
